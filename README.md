# Південноукраїнськ — Інтерактивна карта ГПВ ДПЕМ

Веб-додаток, **PWA** (з ярликом на головному екрані Android / iOS) та **Telegram Mini App** для відстеження графіків погодинних відключень (ГПВ) електроенергії у м. Південноукраїнськ (ДПЕМ ПрАТ «Атомсервіс») на базі **OpenStreetMap + Leaflet + Firebase Firestore**.

---

## Основні можливості додатку

### 1. Карта та навігація
- **Реальні контури будинків і підстанцій OpenStreetMap** (500+ будівель Південноукраїнська) із 7-денним локальним кешем у IndexedDB, 12-годинним серверним кешем та вбудованим офлайн-снапшотом.
- **Diff-перемальовування:** при зміні слота часу, дати або фільтрів перемальовуються лише будівлі, чий стан реально змінився.
- **48 слотів часу (по 30 хв)** + кнопка «Зараз» + автопрокрутка дня («День / Пауза»).
- **Календар вибору дати** замість звичайного списку (показує доступні дні графіка з ДПЕМ).
- **Об'єднаний режим «Світло / Без світла»:** при рідкісних перемиканнях об'єднує слоти перемикань у чисті блоки «Зі світлом» / «Без світла» одночасно на карті, панелі черг, інспекторі будинку та сторінці обраних (можна перемкнути назад на детальний вигляд в 1 клік).
- **Фільтри:** по 12 підчергах (`1-І` … `6-ІІ`), по фідерах/підстанціях, по будинках із колізіями (2+ черги).
- **Пошук з автодоповненням** по вулиці, номеру будинку та власних точках.
- **Світла та Темна тема** (синхронізується з PWA status bar та Telegram Mini App header).

### 2. Окрема сторінка моніторингу «Обрані»
- Кнопка **«Обрані»** у верхній панелі відкриває повноцінну окрему сторінку відстеження для **«Мій дім»** та всіх збережених адрес (Робота, Батьки, Офіс, Школа тощо) з примітками.
- **Живий зворотний відлік** до наступного відключення/ввімкнення на кожній картці.
- **Порівняльна 24-годинна матриця** всіх обраних адрес одна під одною з лінією поточного часу.
- **Згруповані інтервали на добу** (напр. `00:00–08:00 (8 год)` · `08:00–12:00 (4 год)` · `12:00–24:00 (12 год)`) та підрахунок сумарних годин зі світлом / без світла.
- Миттєвий перехід назад до карти без перезавантаження контурів.

### 3. Режими роботи: Перегляд / Редагування / Адмін
- **Перегляд:** безпечний режим для мешканців — карта, календар, обрані, «Мій дім», історія вказань.
- **Редагування:**
  - **«Вказати точку» без адреси:** клік у будь-яке місце карти → задання назви, підчерги, фідера, примітки (зберігається у спільну базу Firestore для всіх).
  - **Тимчасові переноси фідерів:** переведення окремих будинків або вулиць на іншу чергу (пунктирна обводка на карті).
  - **Уточнення колізій (2+ черги):** вибір основної черги або режиму (`основна`, `під'їзди`, `квартири + ліфти`).
  - **Окрема вкладка «Історія»:** хронологічний журнал усіх доданих/видалених точок та змін колізій.
- **Адмін:**
  - **Дашборд аудиту** (`24 год / 7 днів / 14 днів`): унікальні анонімні та залогінені користувачі, онлайн за 15 хв, інтерактивні графіки заходів і правок, топ редакторів, жива стрічка подій.
  - **Команда та запити прав (RBAC):** розгляд заявок, видача ролей, бан/розбан, видалення.
  - **Джерела даних:** ручне завантаження `off_graf.html`, налаштування URL API, інтервалу опитування, очищення кешу OSM, експорт/імпорт JSON-бекапу.

### 4. PWA та Telegram Mini App
- **PWA (Progressive Web App):** Web App Manifest, Service Worker (`vite-plugin-pwa`), комплект PNG-іконок (`192×192`, `512×512`, `maskable` для Android, `apple-touch-icon.png` 180×180 для iOS), вбудована кнопка **«Встановити»** (Android/Desktop) та покрокова інструкція для **iPhone Safari**, офлайн-індикатор та кешування останніх графіків.
- **Telegram Mini App:** автоматичне розгортання (`ready()`, `expand()`), блокування випадкового закриття свайпом при перетягуванні карти (`disableVerticalSwipes()`), синхронізація кольору шапки з темою, нативна кнопка «Назад» (`BackButton`) для закриття модалок/сторінки обраних, вібровідгук (`HapticFeedback`), deep-link по чергах (`startapp=q_3_1`).
- **Вхід через Google та Telegram:**
  - **Google Sign-In (Firebase Auth):** авторизує спільні правки в Firestore, запити прав та ролі.
  - **Telegram Auth (`/api/auth/telegram`):** криптографічна перевірка `initData` (Mini App) та Telegram Login Widget (браузер) через **HMAC-SHA256** з `timingSafeEqual` і перевіркою свіжості `auth_date` (сесійний Bearer-токен зберігається лише в оперативній пам'яті JS, без `localStorage`).

## Система ролей і правила безпеки (RBAC)

Усі правила **гарантовано перевіряються на рівні бази даних Firebase Firestore (`firestore.rules`)**, а не лише в інтерфейсі:

| Роль | Як отримати | Перегляд карти та обраних | Спільні правки (точки, переноси, колізії) | Розгляд запитів і видача ролей | Бан / Розбан | Повне видалення ролі | Дашборд аудиту Firestore |
| :--- | :--- | :---: | :---: | :---: | :---: | :---: | :---: |
| **Гість (анонім / Telegram)** | За замовчуванням | Так | Ні (лише локально) | Ні | Ні | Ні | Ні |
| **Перегляд (Google)** | Вхід через Google | Так | Ні — може подати **запит на права** | Ні | Ні | Ні | Ні |
| **Редактор (`editor`)** | Схвалення запиту адміном | Так | **Так** (свої правки) | Ні | Ні | Ні | Ні |
| **Адмін (`admin`)** | Схвалення запиту адміном / супер-адміном | Так | **Так** (усі записи) | **Так** (`editor` або `admin`) | **Лише редакторів** або **адмінів, яких додав особисто** (`grantedByUid == uid`) | Ні | Статистика заходів |
| **Супер-адмін** | Верифікований email власника (`derevyov@gmail.com`) | Так | **Так** (повний доступ) | **Так** (`editor` або `admin`) | **Будь-яких** адмінів і редакторів | **Так (тільки Супер-адмін)** | Повний доступ |
| **Забанений (`banned`)** | Бан від адміна / супер-адміна | Так | **Заблоковано на рівні Firestore** | Ні (не може слати нові запити) | Ні | Ні | Ні |

### Ключові захисні механізми (`firestore.rules` + сервер)
1. **Неможливість підміни автора додавання (`grantedByUid`):** делегований адмін не може змінити поле `grantedByUid`, щоб «перехопити» чужого адміна та забанити його.
2. **Миттєвий бан:** щойно `status` стає `'banned'`, Firestore миттєво відхиляє будь-які спроби запису цього користувача з `PERMISSION_DENIED`.
3. **Захист геоданих:** координати нових точок обмежені межами Південноукраїнська (`lat: 47.70..47.95`, `lng: 31.00..31.35`), довжини всіх рядків та масивів суворо обмежені.
4. **Ізоляція приватних даних:** домашня адреса (`/userPrefs/{uid}`) доступна лише самому власнику (`list` повністю заборонено).
5. **Незмінний журнал:** `/assignmentHistory` та `/auditEvents` забороняють `update` (append-only).
6. **Секрети тільки на сервері:** `TELEGRAM_BOT_TOKEN`, `CARTO_API_KEY`, `SESSION_SIGNING_SECRET` ніколи не потрапляють у клієнтський бандл.

## Оптимізація під безкоштовний хостинг (до 50+ користувачів)
- Фонове опитування ДПЕМ раз на **10 хвилин** і **зупиняється, коли вкладка згорнута** (`document.hidden`).
- Серверний кеш `/api/dpem` — **5 хв**, браузерний `Cache-Control: 180s`.
- Контуры будинків `/api/osm` — **7 днів** у IndexedDB + **12 годин** на сервері + локальний снапшот.
- Облік візитів — максимум 1 легкий запит за сесію (10-хвилинна дедуплікація на сервері).
- Аудит і список ролей підписуються **лише за вимогою** (коли адмін відкриває вкладку Адмін / Дашборд / Права).
- Обмеження вибірок Firestore (`limit(100)` / `limit(250)`) → витрата **< 5%** від безкоштовної денної квоти Firestore Spark.
